### ⚡ About Me

<img align="right" src="https://media.giphy.com/media/qgQUggAC3Pfv687qPC/giphy.gif" width="180" style="border-radius: 10px;" />

Soy un estudiante de doble titulación (**DAM + DAW**) con un background único en **Ciberseguridad**. Mi objetivo es fusionar estos mundos: construir aplicaciones backend robustas y frontends ágiles, pero siempre con la seguridad como cimiento desde la primera línea de código.

* 🔭 I’m currently working on **APIs REST con Spring Boot** y **Frontend dinámico con React**.
* 🌱 I’m currently learning **Arquitectura de Microservicios** y metodologías **DevSecOps**.
* 🎯 Goal: Convertirme en un referente en el desarrollo de software seguro.
